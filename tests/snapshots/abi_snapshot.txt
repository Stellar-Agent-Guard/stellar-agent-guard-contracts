# contract error with its numeric code and reason symbol. Any diff to
# this file is a potential breaking change for consumers.
#
# Scope:
# - Functions: all `pub fn` entrypoints of `PolicyEngine` plus the
#   host-invoked `__check_auth` (CustomAccountInterface), from src/lib.rs.
# - Types: every `#[contracttype]` item in src/types.rs (policy, ledger,
#   status, and advisory shapes) plus `RecipientLedger` in src/window.rs
#   (a #[contracttype] in a private module, listed for completeness
#   because it still shapes the XDR surface).
# - Errors: every `Error` variant in src/types.rs with its discriminant
#   (the on-chain `Error(Contract, #N)`) and its `reason()` symbol (the
#   `auth_checked` topic and `check`/`check_detailed` block reason).
#   Events are pinned separately by src/event_audit_tests.rs.
